# Portfolio Website

A personal portfolio site for presenting a technology stack and selected
projects. The projects page uses a channel-style sidebar to browse write-ups for
work such as ScriptQuest and HyperSpace, while the home page introduces the
author and highlights technologies.

## Stack

Next.js 13, React, TypeScript, Tailwind CSS, and React Icons. The site is a
frontend app and does not require a database or backend service.

## Run locally

Install Node.js, then run from the repository root:

~~~sh
npm install
npm run dev
~~~

Open [http://localhost:3000](http://localhost:3000). To create a production
build and serve it locally:

~~~sh
npm run build
npm run start
~~~

The source includes the content and visuals for the portfolio; update those
components and the public assets to customize the site.
